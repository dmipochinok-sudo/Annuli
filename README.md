# Annuli

Проект приложения для издательства книг семейной истории. Позволяет импортировать данные из други приложений в формате GEDCOM, систематизировать архивную информацию и документы, экспортировать весь набор текстовых данных о персоне в единый текстовый файл для передачи в верстку.
