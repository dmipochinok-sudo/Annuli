# Дизайн-система v2 и CMS главной страницы

## Что получится

1. Сайт полностью переходит на дизайн-систему v2: новая компактная шапка, обновлённые токены светлой и тёмной темы, инверсная карточка избранного тарифа, микро-анимации блока «Подход», всплывающие уведомления.
2. У вас появляется панель управления содержимым главной страницы: тексты RU/EN, изображения (герой, логотипы) и список дополнительных услуг. Правки сохраняются в облаке и видны всем посетителям сайта.

## Часть 1. Дизайн-система v2

### Расхождения со спецификацией и как их решаем

- **Шапка.** Сейчас старая крупная шапка v1 (большое «Annuli» по центру, отдельная строка навигации). Переверстаем в компактную: тонкая служебная полоса 32 px, липкая полоса 56 px с кольцевой маркой и навигацией, узкая редакционная полоса с тегами. Мобильное меню-бургер сохраняется.
- **Шрифты.** Оставляем те, что подключены сейчас (Playfair Display, PT Serif, PT Sans) и текущий способ подключения — менять не будем.
- **Переключение темы.** Спецификация использует `data-theme`, в проекте тема переключается классом. Оставим текущий механизм и добавим поддержку `data-theme` как синоним, чтобы стили из файла работали без правок.
- **Личный кабинет и приложение.** Они уже используют семантические токены проекта, поэтому новые токены v2 подключаем как единый источник, а старые имена сохраняем как псевдонимы — переверстка кабинета и приложения не требуется.
- **Не реализуем сейчас** (нет этих блоков на сайте): таблица сравнения тарифов и поле телефона с выбором кода страны. Стили из системы оставим в файле, но разметку не добавляем.

### Работы

- Перенести токены v2 (цвета, инверсная featured-поверхность, типографика, отступы, метрики шапки и CMS, z-слои, задержки анимаций) в общий файл стилей проекта, сохранив текущие псевдонимы.
- Заменить компоненты шапки: служебная полоса, компактная шапка с маркой, навигация, полоса-мастхед, мобильное меню; футер привести к v2.
- Обновить карточки тарифов на инверсные токены (избранный тариф — последний, самый дорогой), добавить микро-анимации «Подхода» и общий стиль фокуса.
- Добавить компонент всплывающего уведомления (toast) для CMS и формы.
- Учесть `prefers-reduced-motion` для всех новых анимаций.

## Часть 2. CMS главной страницы

### Расхождения с документом CMS.md

- **Хранение.** В документе — только браузер. Делаем в облаке: тексты, картинки и список услуг хранятся в базе проекта и видны всем.
- **Вход.** Отдельный локальный пароль не делаем: панель открывается только вашей учётной записью с ролью администратора (текущая авторизация проекта).
- **Разделы.** Из 12 разделов документа реализуем те, что соответствуют текущей странице: изображения, шапка, герой, заголовки секций, подход, процесс, тарифы, дополнения, цитата, контакты и форма, футер. Раздел «Сравнение» пропускаем до появления таблицы на сайте.
- **Тексты.** На сайте тексты сейчас записаны прямо в коде, а не в атрибутах разметки. Вводим слой ключей: у каждого текста появляется ключ и значение по умолчанию, а CMS переопределяет его. Поведение для посетителя то же, что в документе.

### Работы

- Таблицы в базе: содержимое (ключ + текст RU/EN), список дополнительных услуг (код, цена, название/описание/примечание RU/EN, порядок) и настройки изображений. Чтение — открытое для сайта, изменение — только администратору.
- Изображения (герой, логотип шапки, логотип футера) загружаются в хранилище проекта с уменьшением перед отправкой; ссылки хранятся в базе.
- Страница `/admin/cms`, доступная только администратору, во всю ширину экрана, в стилистике v2: панель инструментов 44 px (Сохранить / Сбросить всё / Закрыть), навигация разделов 240 px слева (на мобильном — горизонтальная лента), поля RU/EN парами, слоты изображений с превью 96×60.
- Менеджер услуг: добавить, изменить порядок стрелками, удалить с двухшаговым подтверждением, автонумерация.
- Кнопка входа в CMS в шапке — видна только администратору.
- Публикация: «Сохранить» пишет всё разом и обновляет главную страницу; «Сбросить всё» с подтверждением возвращает значения по умолчанию.
- Уведомления по событиям (сохранено, изображение обновлено, услуга добавлена/удалена) — тексты из документа.
- Клавиатура и доступность: Escape закрывает панель, единый фокус-контур, подписи для кнопок.

## Технические детали

- Токены v2 добавляются в `src/styles.css` через `@theme inline` + `:root` / тёмная тема; шрифты — пакеты `@fontsource`, импорт в начале файла стилей.
- Шапка/футер: правки в `src/components/site/SiteHeader.tsx`, `SiteFooter.tsx`, `Logo.tsx` (stroke-марка).
- Контент: новый модуль `src/lib/cms/content.ts` со словарём ключей и значениями по умолчанию (источник — текущие строки `src/components/site/sections.tsx`), хук чтения с подстановкой значений из базы; секции переводятся с прямых строк на ключи.
- Данные: таблицы `site_content`, `site_addons`, `site_images`; чтение через публичный клиент, запись — через серверные функции с проверкой роли администратора; RLS на чтение всем, запись `is_admin()`.
- Изображения: bucket `annuli-media`, папка `site/`, уменьшение на клиенте (герой до 1600 px JPEG .82, логотипы до 128 px).
- Маршрут `src/routes/_authenticated/admin/cms.tsx` с проверкой роли и редиректом для не-админа.

## Порядок работ

1. Токены и шрифты v2, синонимы тем.
2. Компактная шапка, футер, тарифы, микро-анимации, toast.
3. Слой контент-ключей и значения по умолчанию.
4. Таблицы и серверные функции CMS.
5. Панель CMS: тексты, изображения, услуги, публикация.
6. Проверка на мобильном и десктопе, светлая и тёмная тема, обновление документации проекта.
