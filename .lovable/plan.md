# Annuli: архив по персонам, экспорт документов и редизайн

Три связанных блока: структура резервного архива, новый «Архивный раздел» + TXT-досье, и переход интерфейса на тёмную дизайн-систему из Design_System.md и скриншотов.

## 1. Резервный архив базы: папки по персонам

Сейчас все сканы падают плоско в `images/`. Станет:

```text
Annuli_2026-08-24.zip
├── data.json
├── annuli.ged
└── images/
    └── N_5_3 Вениамин Романович Поберский/
        ├── N_5_3.avatar.jpg
        ├── D_5_3_1_стр1.jpg
        └── ...
```

- Имя подпапки: индекс с заменой точек на подчёркивания + ФИО. Персона без индекса/имени — папка по её ID.
- Дубли имён папок и файлов разводятся суффиксом `_2`, `_3`.
- Импорт остаётся полностью совместимым: пути берутся из `_file` в `data.json`, поэтому старые архивы (плоский `images/`) продолжат восстанавливаться без потерь.

## 2. Кнопка «Экспорт в .TXT» и «Создать архивный раздел»

В шапке карточки персоны появятся обе кнопки (как на макетах): «Редактировать», «Экспорт в .TXT», «Создать архивный раздел», «Удалить».

**Экспорт в .TXT** — текстовое досье персоны: основные данные, рождение/смерть, родители и крёстные, браки, дети, служба, воспоминания, список документов с архивными реквизитами.

**Создать архивный раздел** — ZIP только с документами персоны (рождение, смерть, служба, браки, дети, произвольные документы; портрет и фотоальбом не включаются):

```text
Архив N_5_3 Вениамин Романович Поберский.zip
├── D_5_3_1_стр1.jpg
├── D_5_3_1_стр1.txt
├── D_5_3_1_стр2.jpg
├── D_5_3_1_стр2.txt
└── ...
```

Имя файла изображения строится от номера документа в базе (`docId`) и номера страницы. Рядом — одноимённый .txt со всей известной информацией:

- Название документа
- Имя файла изображения
- Расшифровка записи (страницы, при отсутствии — расшифровка документа)
- Архив, Фонд, Опись, Дело, Лист
- Онлайн-ссылка (если заполнена)
- Комментарий (если заполнен)

Пустые поля выводятся как «—», чтобы структура файла была одинаковой для вёрстки книги.

## 3. Редизайн под тёмную схему

Дизайн-система переносится в токены `src/styles.css` (единый источник цвета, без хардкода в компонентах):

- Фоны: `#020408` (тёмный), `#0D1116` (базовый), `#202830` (светлый), обводки `#3D444D` / `#798799`.
- Текст: `#E6E6E6` (яркий), `#CCCCCC` (в полях), `#657180` (вторичный); акцент-ссылка синий, alert `#DB2C2C`, success-зелёный для «Связать».
- Радиусы 8px (контролы) и 16px (карточки), высота контролов 32px, шрифт SF Pro с системным фолбэком.

Компоненты приводятся к макетам:

- **Шапка**: логотип Annuli, поле поиска с кнопкой «Найти», переключатель «Тёмная тема», кнопки «Добавить», «Древо», «Импорт / Экспорт базы».
- **Панель персоны**: имя слева, действия справа.
- **Сайдбар**: селекты «Поколение», «Пол», «Ветви» и карточки персон с миниатюрой, индексом, ФИО и годами жизни.
- **Вкладки**: горизонтальная лента с подчёркиванием активной (на мобильных — прокрутка).
- **Контент**: блоки с заголовком-шапкой (иконка + заголовок капсом), карточки-секции с обводкой, поля с подписью сверху, сетка «Имя / Отчество / Фамилия».
- **Сканы**: сетка слотов-превью с подписью «стр. N» и слотом «Добавить страницу».
- **Кнопки** в вариантах primary / secondary / round / alert / link по состояниям default–hover–pressed–disabled.
- Тёмная тема становится оформлением по умолчанию; светлая сохраняется как переключатель.

Мобильная адаптация (гамбургер-сайдбар, прокручиваемые вкладки, одноколоночные формы) сохраняется.

## Технические детали

- `src/lib/annuli/media.ts`: функция `personFolderName(p)` и генерация имён файлов документов.
- `src/lib/annuli/archive.ts`: `buildArchive` кладёт файлы в подпапки персоны; импорт не меняется.
- Новый `src/lib/annuli/person-export.ts`: `buildPersonTxt(person)` и `buildPersonDocsArchive(person)` (JSZip, оригиналы блобов из IndexedDB).
- `src/routes/index.tsx`: обе кнопки в шапке персоны с тостами прогресса и ошибок.
- `src/styles.css`: новые семантические токены; компоненты `src/components/annuli/*` переводятся на них.
- Проверка: сборка архива и TXT для тестовой персоны через браузерный прогон, визуальная сверка экранов со скриншотами.
- В конце — обновление `legacy/ANNULI_PROJECT_DOCUMENTATION.md`.
