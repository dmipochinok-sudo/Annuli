# Редизайн UI без изменения UX

## Почему в прототипах «поехал» UX

Прототипы — это статичные картинки-мокапы, сгенерированные отдельно от кода. Они показывают только визуальный язык (цвет, плотность, типографику, скругления, тени). Названия и набор вкладок в них — условный наполнитель, а не предложение изменить структуру. Реальная структура приложения остаётся ровно такой, как сейчас.

## Что остаётся неизменным (жёсткое правило)

- Девять вкладок и их порядок: Основное, Рождение, Учеба, Карьера, Военная служба, Смерть, Воспоминания, Архив, Фотоальбом.
- Все блоки и поля внутри вкладок, их порядок и логика.
- Сайдбар со списком персон, поиск, кнопки шапки (древо, база данных, тема), мобильное поведение (гамбургер, оверлей, прокрутка вкладок).
- Импорт/экспорт ZIP+GEDCOM, архивный раздел, дедупликация, лайтбокс — не трогаем.

## Что меняется (только визуальный слой)

1. **Палитра** — мягкий графит вместо жёсткого контраста, бронзовый акцент вместо золота; согласованные светлая и тёмная темы.
2. **Скругления** — сглаженные в стиле iOS/macOS: 8px для контролов, 12px для карточек.
3. **Плотность и иерархия** — единые отступы карточек-секций, заголовки секций, спокойные разделители вместо жирных рамок.
4. **Вкладки** — та же лента с тем же составом, обновлён только стиль активного состояния (бронзовое подчёркивание).
5. **Поля ввода** — единые высоты, фон, состояние фокуса бронзой.

## Технические детали

- `src/styles.css` — заменяются токены oklch (фон, поверхности, границы, акцент), добавляются токены радиусов и теней.
- `src/components/annuli/PersonBasic.tsx` — примитивы `Section`, `Label`, поля: правки только классов Tailwind по токенам.
- `src/routes/index.tsx` — стилизация шапки, сайдбара и ленты вкладок; массив `TABS` не меняется.
- Остальные вкладочные компоненты подхватывают новые токены через общие примитивы; точечные правки классов при необходимости.
- Никаких изменений в логике состояния, хранилище, экспорте и импорте.
