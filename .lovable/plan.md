# Удаление функционала «Скачать старую локальную базу браузера»

## Контекст
Приложение полностью перешло на облачную базу (таблица `persons` + bucket `annuli-media` с изоляцией по владельцу). Кнопка «⬇ Скачать старую локальную базу браузера» в диалоге «💾 База данных» была разовой миграционной операцией и больше не нужна. Соответствующий код (`local-db.ts`, `local-export.ts`) используется только этой кнопкой и является мёртвым.

Проверено: облачный слой `src/lib/annuli/db.ts` не импортирует локальные модули; функции `localPutPerson`/`localDelPerson`/`localImgPut`/`localImgDel`/`localAllPersons`/`localImgGet` не используются нигде вне `local-export.ts`.

## Изменения

1. `src/components/annuli/DbModal.tsx`
   - Удалить `import { buildLocalArchive } from "@/lib/annuli/local-export";`
   - Удалить метод `exportLocal` и его вызов.
   - Удалить кнопку «⬇ Скачать старую локальную базу браузера» и поясняющий абзац под ней в секции «Экспорт».
   - Секция «Экспорт» остаётся с двумя кнопками: ZIP (данные + сканы + GEDCOM) и GEDCOM.

2. Удалить файл `src/lib/annuli/local-export.ts` (целиком).

3. Удалить файл `src/lib/annuli/local-db.ts` (целиком) — весь слой IndexedDB больше не нужен.

## Проверка
- `bunx tsgo --noEmit` — без ошибок (убедиться, что нет висящих импортов).
- Проверить, что `bun run build` проходит.
