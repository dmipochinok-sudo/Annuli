# Группировка тарифов в CMS

## Что изменится
- В разделе «Тексты» вместо одной общей группы «Тарифы» появятся четыре отдельные группы — по одной для каждой карточки тарифа.
- Внутри каждой группы поля будут идти в порядке карточки: уровень тарифа, название, описание, цена, примечание, затем значения «Страниц», «Фотографий», «Интервью», «Древо», «Экземпляров», «Правок» и «Срок».
- Названия характеристик станут фиксированными и исчезнут из редактируемых полей CMS. Редактироваться будут только их значения на русском и английском.
- Общая надпись на кнопке тарифов останется в отдельной небольшой группе общих текстов тарифов.

## Технические детали
- Из списка редактируемых полей исключить ключи `pl.*.s*.lbl`, сохранив их исходные значения для отображения на сайте.
- Добавить отдельные идентификаторы групп `pl.1`–`pl.4` и явную сортировку полей внутри каждой карточки.
- На публичных карточках выводить фиксированные подписи характеристик, а значения продолжить получать из CMS.
- Обновить проектную документацию и проверить типы и отображение CMS.
